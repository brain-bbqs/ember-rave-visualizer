## Changing the vendored viewer

Every part of the viewer is under a license that allows modification, and each one attaches a condition.
MPL-2.0 applies file by file, so changing the engine never changes the app's own MIT license.

> [!NOTE]
> Which condition applies depends on which part you touch, because the HTML is four separately licensed pieces in one file:
>
> | Part of the file                                                         | License                                                                               | Condition if you change it                                                             |
> | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
> | three-brain-js engine bundle (three.js, jsPDF and others bundled inside) | MPL-2.0; the bundled libraries are MIT, BSD or Apache                                 | The changed file stays MPL-2.0, its source must be available, and notices must be kept |
> | threeBrain widget script (the small wrapper)                             | MPL-2.0 (the threeBrain R package)                                                    | Same as above                                                                          |
> | `htmlwidgets.js`                                                         | MIT                                                                                   | Keep the notice                                                                        |
> | Widget settings and the embedded template data                           | Settings: generated by threeBrain's export; data: FreeSurfer Software License, Part B | Changed data must be marked as modified                                                |

## What would be a violation

- Removing license notices.
- Presenting modified template data as the original FreeSurfer files.
- Relabelling the engine code as MIT.
- Distributing a modified engine without its source.
